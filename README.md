## 📝 Basic Concepts

### 1. Variables

Variables are used to store values.

```python
name = "Sachin"
age = 21
```

Here:

* `name` is a variable
* `age` is a variable

### 2. Data Types

Python has different built-in data types such as:

```python
int
float
str
bool
list
tuple
set
dict
```

Example:

```python
x = 10
print(type(x))
```

Output:

```text
<class 'int'>
```

### 3. Lists

A list is used to store multiple items in a single variable.

```python
thislist = ["apple", "banana", "cherry"]
print(thislist)
```

Here:

* `thislist` → variable
* `["apple", "banana", "cherry"]` → list object
* `list` → data type

We can check the data type using `type()`:

```python
print(type(thislist))
```

Output:

```text
<class 'list'>
```

### 4. `type()`

`type()` is a built-in Python function used to check the data type of an object.

Example:

```python
x = 10
print(type(x))
```

Output:

```text
<class 'int'>
```

Another example:

```python
x = ["apple", "banana"]
print(type(x))
```

Output:

```text
<class 'list'>
```
